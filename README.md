# KALO Gifts: Shopify theme

Theme files (`assets`, `config`, `layout`, `locales`, `sections`, `snippets`, `templates`) live at the repo root so Shopify's GitHub integration can read them.

- `import/products.csv`: product import for Shopify (Products > Import). Regenerate with `python import/build_products.py`.
- `SETUP.md`: step-by-step store setup.
